# ADR-005：RNA-seq 表达量作为菌株特异的酶容量约束（相对层，绝对容量仍 unavailable）

状态：accepted（设计契约与方法已定；实现待 RNA-seq 数据到位后按本契约落地，当前无代码）
日期：2026-07-22
关系：在 [ADR-002](002-relative-oe-and-absolute-capacity-layers.md) 相对/绝对分层内、延续 [ADR-004](004-relative-signal-deepening-under-permanent-data-gap.md) 的相对信号深化；数据契约体例参照 [ADR-003](003-fermentation-feedback-minimal-fields.md)；不改变绝对容量 unavailable 的判定

## 背景

- 模型现有相对信号是"通用未标定"的——酶容量用通用假设、非菌株特异。同一模型对一个已高度改造的生产株（本底已增强折叠能力与 UPR、含多拷贝目标基因）和一个 naive 株给相同相对结论，无法反映"这一株哪些酶实际在表达"。
- 绝对 OE/容量数据经三次调研确认公开来源永久缺失（ADR-004）。
- 2026-07-13 hLF 周报佐证模型范围内判断对得上（折叠饱和、运输毒性），但缺的正是菌株特异的表达上下文。
- 将来会拿到 RNA-seq。它恰是"每个基因/酶造了多少"的读数，**天然适配蛋白约束模型**：把 transcript 当酶丰度代理去约束酶容量，可把相对层从"通用"贴向"这一株特异"。
- 为什么不是别的用途：RNA-seq **不**解锁降解层建模（给不了蛋白酶对目标蛋白的底物特异性与降解速率，见记忆「模型范围 vs 湿实验」/架构文档缺口 #7），也**不**产生绝对容量（transcript≠protein、kcat 未标定）。

## 决策

1. **RNA-seq 作为可选、菌株特异的酶容量约束输入**，只收紧相对层；绝对容量/可执行性恒 unavailable、不因 RNA-seq 改变。opt-in、默认关、不改 corrected 基线管道（镜像 ADR-004 各信号的开关体例）。
2. **方法：pc 原生「transcript→酶丰度上界」**。把每个酶的相对 transcript 水平（组内归一化）映射为其在模型里可用容量的相对上界（酶容量 = 丰度代理 × kcat，kcat 沿用现有未标定值）。**不采用 E-Flux/GIMME 那种对反应通量的通用缩放/开关**——蛋白约束模型本就有酶容量维度，直接约束酶丰度语义更干净、更贴合架构。
3. **映射范围两条路**：
   - a. **代谢层**：走已有 GPR（transcript→酶→反应），~1025 个 `PAS_*` 基因直接可用。
   - b. **分泌机器层**：无 GPR，但 curated catalog 的复合体反应名里带有其组成基因名；建一份 **curated「基因→复合体」映射**，让 RNA-seq 也能约束 R1 指认的折叠/分泌 binding 层——**这是比只约束代谢更高价值的目标**。多亚基复合体先按**限速亚基（最小可用丰度）**聚合（保守、与"容量由最缺亚基决定"一致），聚合规则显式记录、可换。
4. **数据契约（输入格式，落地时按此校验）**：
   - 必需列：`gene_id`（映射到模型基因 / 复合体亚基）、`expression`、`unit`（TPM/FPKM/counts 之一）、`sample_id` / `strain` / `condition`、`normalization`（组内归一化方法）。
   - provenance：来源、version/hash、测序与定量管线标识（沿用外部数据 provenance 门槛）。
   - 未映射到模型的基因忽略并计数上报；映射到复合体的按 3b 聚合。
5. **相对性硬约束**：输出仍是相对信号——"这一株的相对候选排序/瓶颈"，不写任何绝对容量资产、不提升任何候选为 `experiment_calibrated` 或绝对可执行；扫描带宽不作容量值。

## 明确保留待定、不在本决策中假设答案

- transcript→protein 的定量关系（是否引入非线性/饱和映射，还是保持线性代理）——先用线性代理，待真实 RNA-seq（若有配对蛋白质组）再定。
- 多亚基复合体聚合规则（限速亚基 vs 几何均值 vs 化学计量加权）——先用限速亚基，看真实数据表现再调。
- 是否用跨样本/条件的差异表达约束（而非单样本绝对水平）——待多条件 RNA-seq 到位再评估。

## 不变量

- 绝对容量/可执行性恒 unavailable，RNA-seq 不改变（延续 ADR-002/ADR-004）。
- 不改 corrected 基线管道的目标、约束或默认求解；表达约束是 opt-in 探针。
- 不修改受保护科学资产（`Model/`、`Enzymedata/`、GPR）；curated「基因→复合体」映射是新增的证据层映射，不改模型矩阵。
- transcript≠protein、kcat 未标定，结论只在相对层解读；诚实边界随输出透出（类比 ADR-004 各信号的 warnings）。

## 影响

优点：把相对信号从"通用未标定"提升到"菌株特异"，且经 curated「基因→复合体」映射能触达 R1 指认的分泌 binding 层——这是 RNA-seq 对本项目最高价值、也最贴合蛋白约束模型架构的用法；数据契约先定，数据一到即可落地，无需重新设计。代价：需维护一份 curated「基因→复合体」映射（多亚基聚合规则有主观性，已标为待定）；transcript≠protein 的固有噪声进入相对层，须在输出诚实标注；实现前无真实数据，只能用脱敏 fixture 验证管道。
