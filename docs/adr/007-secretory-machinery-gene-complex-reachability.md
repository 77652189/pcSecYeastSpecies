# ADR-007：分泌机器的「基因 ↔ 复合体」映射作为可达性层

状态：accepted（方向已定；策展范围与责任人未决，见下）  
日期：2026-07-28  
关联：补充 [ADR-001](001-external-capacity-candidate-promotion.md)（外部候选审核门禁）、[ADR-002](002-relative-oe-and-absolute-capacity-layers.md)（相对层 / 绝对层分离）、[ADR-004](004-relative-signal-deepening-under-permanent-data-gap.md)（免数据相对信号）。**不替代**任何既有 ADR。

## 背景：两条平行候选路径，用户被迫承担模型的实现细节

模型的 GPR（基因-反应关联）**只覆盖代谢反应**；分泌机器（伴侣蛋白、转运子、糖基化、COPII、蛋白酶体等）是 **2793 个复合体形成反应、零基因关联**（已核实）。由此形成两条互不相交的候选路径：

| | 基因级路径 | 复合体 / 反应级路径 |
| --- | --- | --- |
| 覆盖对象 | 约 1025 个代谢基因（走 GPR） | 2793 个分泌机器复合体形成反应 |
| 发现方式 | 全基因组 KO/OE 筛查 | 策展库（`SECRETION_GENE_CATALOG`，69 条） |
| 实测价值 | 效应多为亚百分比，且常伴巨大生长代价 | **项目全部真实杠杆都在这里**（PDI1/ERO1 折叠轴、KAR2、OCH1、PMT） |

2026-07-28 查实的关键事实：策展 69 条里**只有 13 条能按基因跑**（2 KO + 11 OE 代理），其余 **56 条全部带着模型里真实存在的复合体反应**——包括 `sec_Pdi1p_complex_formation`，即架构文档记录的 hLF 头号 OE 杠杆（+8.15%）。原因是结构性的、不是数据缺口：37 条同源给出了 Pichia 位点但该位点不在模型基因集（`rbh_not_in_model`），19 条策展名本身就是复合体或家族（OST 复合体、KTR、MPOLI/II），没有单一基因。

**产品后果**：这条模型内部的分裂此前被直接暴露给用户——候选面板既不显示策展俗名、也不显示可跑的反应 ID，把"仅复核/模型外"当成死胡同呈现，实际上最有价值的杠杆全在那一档里（已由 `389721f` 修正显示与措辞）。全基因组筛查也**够不到**这些反应（交叉核对：覆盖 0 个）。

## 决策

1. **界面不得把"基因 vs 复合体反应"的分裂交给用户承担。** 研究员的心智是"我要动 PDI1"，是基因还是反应属模型实现细节，由系统路由到对应输入。统一的候选选择入口按**分泌环节**组织，基因与复合体并列可选。四个 KO/OE 输入框降为高级 / 诊断入口。
2. **新增「基因 ↔ 复合体」映射作为独立的可达性层**，用来回答两个方向的问题：
   - 正向（覆盖面）：让基于基因的筛查能够触达分泌机器复合体；
   - 反向（实验可执行性）：把"过表达某复合体反应"翻译成"实验室去过表达哪几个基因"。
3. **可达性 ≠ 准确度。** 本层只扩大模型**够得到的干预点范围**，不提升绝对预测能力。绝对容量按 ADR-002 恒 `unavailable`；不因本层放宽 ADR-001 的正式资产门禁。
4. **明确不做：给代谢基因补更多外部 GPR。** 1025 个代谢基因已被系统覆盖，且实测效应处于亚百分比区间并常伴生长代价；在该区加密度属低价值。外部证据 GPR overlay 保持现状（实验性、默认关闭）。

## 数据契约（映射条目的最低要求）

每条「基因 → 复合体反应」映射必须携带：

- `pichia_gene_id`（模型可识别的位点）与 `complex_reaction_id`（模型中真实存在的复合体形成反应）；
- `evidence_source`：策展文献 / 同源 RBH / 外部 GEM，含 version、retrieved_at、license 或引用；
- `subunit_role`：该基因是复合体的必需亚基、可替换同工酶，还是仅辅助；
- `stoichiometry_status`：亚基化学计量是否已知——**未知时不得据此声称单基因 OE 能提升复合体容量**（沿用既有"复合体亚基默认不做单基因 OE"的约定）；
- `review_status`：人工复核状态，未复核不得进入可执行路径（沿用 ADR-001 门禁）。

映射落在与正式科学资产分离的策展层；不改写 `Model/`、`Enzymedata/` 等受保护资产的 GPR，也不写回参考模型。

## 未决（需产品 / 生物学拍板，非软件问题）

- **策展范围与责任人**：哪些复合体先做、由谁判断映射可信（生物学判断，不能由代码决定）。
- 是否先落软件侧（数据契约 + 导入 + 门禁 + 空态优雅降级），把位置留好等策展数据——与 [ADR-005](005-rnaseq-expression-constrained-enzyme-capacity.md) 的做法一致。

## 后果

- 正面：真正的杠杆区变得可发现、可选、可翻译成实验动作；筛查覆盖面从"仅代谢"扩到"含分泌机器"；"基因归属待复核"的 56 条得以逐步收敛。
- 代价：策展与复核成本（生物学判断）；映射错误会把无效候选包装成可执行，故 `review_status` 与 `stoichiometry_status` 门禁不可省。
- 风险边界：本层不产生绝对容量、不解锁目标蛋白降解层建模、不改默认 solver、不动 glucose 的 `corrected_reference` 基准。
